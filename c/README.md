# C e C++

Estudos em C, C++ e Arduino, organizados por tema.

| Pasta | Conteúdo |
|---|---|
| [`fundamentos/`](fundamentos) | Exercícios de C++ de 2022: menus e calculadora, cálculo de IMC, relação cintura-quadril, consumo de combustível, média de notas, variáveis e operações. |
| [`estruturas-e-algoritmos/`](estruturas-e-algoritmos) | `ordenacao` (bubble, insertion e selection sort), `arvores` (busca binária), `grafos` (busca em profundidade e Dijkstra) e `ponteiros` (lista encadeada). |
| [`aplicacoes/`](aplicacoes) | `checksum-xor-8bits` (cálculo de checksum XOR de 8 bits), `hotel-reservas` (sistema de reservas de hotel em C, com dados em JSON e documentação) e `menu-lancamento-notas` (menu de lançamento de notas em C++). |
| [`arduino/`](arduino) | Sketches para Arduino e ESP32: `sensor-temperatura` (sensor DS18B20), `display-tft-serial-msgs` (display TFT com touch), `led-firebase` e `reset-esp32` (controle pelo Firebase) e `soma-trigonometrica`. |

Os projetos de Arduino que usam Wi-Fi e Firebase esperam um arquivo `secrets.h` local, que não é versionado. Use o `secrets.example.h` de cada pasta como modelo.
