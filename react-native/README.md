# React Native

Estudos com React Native e Expo (agosto de 2024), feitos com Expo 51, React Native 0.74 e React 18.

| Projeto | Conteúdo |
|---|---|
| [`calculadora-simples`](calculadora-simples) | Calculadora com as quatro operações (soma, subtração, multiplicação e divisão) entre dois números. Em JavaScript. |
| [`wise-mage`](wise-mage) | Aplicativo de respostas rápidas: ao tocar em "Responder", sorteia uma resposta como "SIM..." ou "JAMAIS!", sobre a imagem de um mago. Em TypeScript. |
| [`estados-ibge`](estados-ibge) | Lista os estados do Brasil e, ao escolher um, mostra seus municípios, consultando a API pública de localidades do IBGE com `axios` e navegação em pilha. Em TypeScript. |

## Como executar

Em cada projeto, dentro da pasta:

```bash
npm install
npx expo start
```

Em seguida, abra o aplicativo no Expo Go, em um emulador Android ou iOS, ou no navegador. Os scripts `npm run android`, `npm run ios` e `npm run web` também estão disponíveis.
