# Ruby

Estudos de fundamentos da linguagem Ruby, organizados por tema.

| Pasta | Conteúdo |
|---|---|
| [`condicionais/`](condicionais) | `if`/`else`, `elsif`, `case`/`when`, operador ternário e um exercício que converte um número em letra do alfabeto. |
| [`estruturas/`](estruturas) | Listas (arrays), listas de strings e hashes. |
| [`loops/`](loops) | `each`, `for`, `loop do`, `map`, `times` e `while`. |
| [`strings/`](strings) | Operações com strings, leitura de entrada com `gets` e `strip`/`slice`. |
| [`funcoes/`](funcoes) | Definição de funções. |
| [`matematica/`](matematica) | Operações matemáticas. |
| [`simbolos/`](simbolos) | Símbolos. |

Cada arquivo é um script independente: `ruby caminho/do/arquivo.rb`.
